Shows the CPU, memory, disk and network usage of the machine the Paseo daemon runs on, as one line in the sidebar footer.

The line reads like the built-in usage summary: an icon and percentage for CPU, RAM and disk, with a small meter when the sidebar is wide enough, followed by download and upload speed side by side under one icon. The disk figure adds all local disks together. Meters and numbers turn yellow above 70 percent and red above 90 percent. On a narrow sidebar the network speeds are dropped first, then disk. Press the line for a popover with about three minutes of history for each metric, the usage of each local disk, plus uptime and load average.

The daemon samples the host every two seconds, disks every thirty, and keeps the history in memory. History resets when the plugin reloads or the daemon restarts. Each connected host reports its own numbers.

Percentages below 10 show one decimal, so a nearly idle host reads 0.4% rather than 0%. On Linux, CPU usage comes from `/proc/stat`; I/O wait counts as idle and steal time, which a VPS loses to its hypervisor, counts as busy. Memory uses the available-memory figure from `/proc/meminfo` on Linux, so the page cache is not counted as used. On macOS, memory uses `vm_stat`: anonymous pages minus purgeable pages, plus wired pages and the physical pages occupied by the compressor, multiplied by the reported page size. This excludes file-backed cache and follows Activity Monitor’s app + wired + compressed memory accounting. Network speed sums all interfaces except loopback and common virtual ones (veth, docker, bridge). Disks are the filesystems in `/proc/mounts` backed by a block device (plus ZFS), each device counted once; network mounts, memory-backed filesystems and read-only images such as snap packages are left out. Disk percentages follow `df`: space reserved for root counts as neither used nor free. Network speed and the disk list need Linux; on other systems only CPU, RAM and the root disk are shown.

The plugin only reads local system counters. The host name and these statistics are shown to every Paseo client connected to the daemon, including remote ones; the plugin contacts no other service.
